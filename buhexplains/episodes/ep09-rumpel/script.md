# ep09-rumpel

Is the Rumpelstiltskin dance from a real eighties movie?
You see, the Rumpelstiltskin we all know and love tip toes for a princess while Riff Raff plays.
The song is real. Riff Raff put it out in twenty fourteen.
And there really was a Rumpelstiltskin movie in nineteen eighty seven.
So the clip must be from that, right?
Nope. That dance was never in it.
The whole clip was made with AI, and posted on Instagram this August.
So Rumpelstiltskin is from an eighties movie that never existed.
